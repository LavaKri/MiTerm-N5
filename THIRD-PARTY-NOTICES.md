## pyte (LGPL v3)

pyte is kept as separate source files in the `_internal\pyte` folder, not inside an archive.
You can replace it with another version: edit or replace the files of that folder.
pyte reste en fichiers séparés dans le dossier `_internal\pyte`, pas dans une archive.
Vous pouvez le remplacer par une autre version : modifiez ou remplacez les fichiers de ce dossier.
